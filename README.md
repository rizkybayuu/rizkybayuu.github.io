## 🚀 Running Locally

No npm dependencies or compilation steps required! Simply clone and serve with any static web server:

```bash
# Clone the repository
git clone https://github.com/rizkybayuu/rizkyby.web.github.io.git
cd rizkyby.web.github.io

# Start a local static HTTP server (Python 3)
python3 -m http.server 8080

# Or using Node.js
npx serve .
```

Then open your browser at `http://127.0.0.1:8080/`.
